# NPI Follow-up

เว็บสำหรับติดตามเลขออเดอร์จาก Google Sheet แท็บ `USE` โดยแสดงข้อมูลสำคัญตามหัวคอลัมน์จริง:

- `สถานะสินค้า`
- `โทรตามลูกค้า` — ถ้ามีข้อมูลจะแสดงเป็น `โทรแล้ว`
- `Date Call` — วันที่เจ้าหน้าที่โทร
- `Comment` — ความคิดเห็นของลูกค้า

ชื่อพนักงานจากคอลัมน์ `พนักงาน` จะถูกแปลงเป็นชื่อจาก mapping ใน `src/lib/sheet.js` และแสดงในหน้าเว็บ

## เริ่มใช้งาน

```bash
npm install
npm run build
npm run preview
```

จากนั้นเปิด URL ที่ Vite แสดงผล เช่น `http://127.0.0.1:4173/`

`npm run dev` อาจได้รับผลจาก `package.json` และ `tsconfig.json` ของโฟลเดอร์แม่ `/Users/et` ที่มี merge conflict อยู่ภายนอกโปรเจกต์นี้ จึงใช้ `build` + `preview` เป็นวิธีทดสอบที่เสถียรใน workspace นี้

## การใช้งาน

1. แอปจะอ่านข้อมูลจากแท็บ `USE` อัตโนมัติเมื่อเปิดหน้า
2. ใช้ช่องค้นหาด้านบนเพื่อค้นหาเลขออเดอร์ พนักงาน หรือ Comment
3. คลิกแถวเพื่อดูรายละเอียด `สถานะสินค้า`, `โทรตามลูกค้า`, `Date Call` และ `Comment`
4. กด `อัปเดต USE` เพื่ออ่านข้อมูลล่าสุดจาก Google Sheet
5. กด `เปิด Google Form` เพื่อเพิ่มเลขจองใหม่

ชีตต้องเปิดให้ผู้ใช้เว็บอ่านข้อมูลได้ เพื่อให้ CSV/Visualization endpoint ทำงาน หากอ่านไม่ได้ แอปจะแสดงโหมดออฟไลน์จากข้อมูลสำรองในเครื่อง
