# NPI Booking Desk

เว็บสำหรับพนักงานค้นหาเลขออเดอร์จาก Google Sheet และเปิด Google Form เพื่อบันทึกเลขจองใหม่

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

สำหรับ build production:

```bash
npm run build
npm run preview
```

## แหล่งข้อมูล

- Google Form: แบบฟอร์มจริงถูกผูกไว้ใน `src/App.jsx`
- Google Sheet: ใช้แท็บ `USE` โดยระบุ `SHEET_TAB_NAME`, `SHEET_ID` และ `SHEET_GID` ใน `src/lib/sheet.js`
- ชีตต้องเปิดให้ผู้ใช้เว็บอ่านข้อมูลได้ จึงจะดึง CSV/Visualization endpoint ได้จากเบราว์เซอร์

ระบบค้นหาจะอ่านจากแท็บ `USE` และแสดงข้อมูลจริงจากคอลัมน์ `สถานะบิลมัดจำ`, `เลขออเดอร์`, `พนักงาน` (แปลงเป็นชื่อในหน้าเว็บที่คอลัมน์ `เป็นของใคร`), `สถานะสินค้า`, `รุ่น iPhone` (รองรับหัวตาราง `Product` ด้วย), `Lot รับของลูกค้า` (รองรับหัวตาราง `Lot Date` ด้วย), `โทรตามลูกค้า`, `Date Call` และ `Comment` เมื่อเชื่อมต่อสำเร็จ โดย `รุ่น iPhone` และ `Lot รับของลูกค้า` จะแสดงต่อจาก `สถานะสินค้า` ในการ์ดเลขจอง หากปลายทางอ่านไม่ได้จะเปลี่ยนเป็นโหมดสาธิตด้วยข้อมูลตัวอย่างที่ตรวจสอบแล้ว

สีสถานะในหน้าผลลัพธ์จะแยกตามข้อมูลจริง: ใช้บิลมัดจำแล้ว/โทรแล้ว/มีวันที่โทร/มี Comment เป็นสีเขียว, ของเข้าแล้วเป็นสีฟ้า และสถานะที่ยังไม่ได้ใช้บิลมัดจำ/ของยังไม่เข้า/ยังไม่โทร/ไม่มีข้อมูลเป็นสีแดง

ส่วน `เลขจองของพนักงาน` ให้เลือกชื่อพนักงานเพื่อดูเฉพาะเลขจองของคนนั้นที่ยังไม่ได้ใช้บิลมัดจำและสินค้าเข้าแล้ว ระบบจะดึงข้อมูลใหม่เมื่อเปิดหน้า กดรีเฟรชเองได้ และอัปเดตอัตโนมัติทุก 5 นาที

ชื่อพนักงานถูกจับคู่จากรหัสใน `EMPLOYEE_NAMES_BY_ID` โดยใช้รายชื่อจากภาพที่ให้มา หากมีพนักงานใหม่ให้เพิ่มรหัสและชื่อใน object นี้
