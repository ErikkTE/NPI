# NPI Booking Desk

เว็บสำหรับพนักงานค้นหาเลขออเดอร์จาก Google Sheet และเปิด Google Form เพื่อบันทึกเลขจองใหม่

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

สำหรับ build production:

```bash
npm run build
npm run preview
```

## แหล่งข้อมูล

- Google Form: แบบฟอร์มจริงถูกผูกไว้ใน `src/App.jsx`
- Google Sheet: ใช้แท็บ `USE` โดยระบุ `SHEET_TAB_NAME`, `SHEET_ID` และ `SHEET_GID` ใน `src/lib/sheet.js`
- ชีตต้องเปิดให้ผู้ใช้เว็บอ่านข้อมูลได้ จึงจะดึง CSV/Visualization endpoint ได้จากเบราว์เซอร์

ระบบค้นหาจะอ่านจากแท็บ `USE` และแสดงข้อมูลจริงจากคอลัมน์ `สถานะบิลมัดจำ`, `เลขออเดอร์`, `พนักงาน` (แปลงเป็นชื่อในหน้าเว็บที่คอลัมน์ `เป็นของใคร`), `สถานะสินค้า`, `โทรตามลูกค้า`, `Date Call` และ `Comment` เมื่อเชื่อมต่อสำเร็จ หากปลายทางอ่านไม่ได้จะเปลี่ยนเป็นโหมดสาธิตด้วยข้อมูลตัวอย่างที่ตรวจสอบแล้ว

ถ้าคอลัมน์ `โทรตามลูกค้า` มีข้อมูล ระบบจะแสดงเป็น `โทรแล้ว`; ถ้าว่างจะแสดง `ยังไม่มีข้อมูล` พร้อมแสดงวันที่โทรและ Comment ในการ์ดรายละเอียด

ชื่อพนักงานถูกจับคู่จากรหัสใน `EMPLOYEE_NAMES_BY_ID` โดยใช้รายชื่อจากภาพที่ให้มา หากมีพนักงานใหม่ให้เพิ่มรหัสและชื่อใน object นี้
